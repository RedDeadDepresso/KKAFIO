# Tasks

KKAFIO is a list of tasks. Tick the ones you want in the GUI, configure their options, and press **Start**; they run in order. [Presets](../presets.md) tick and configure a useful set for you.

| Task | What it does |
|---|---|
| [Create Backup](create-backup.md) | Archives `UserData`, `Mods` and/or `BepInEx` into a `.7z`. |
| [Download Contents](download-contents.md) | Downloads cards from db.bepis.moe, koikatsucards.com, pixiv, pawchive, gofile, catbox, Mega and Google Drive. |
| [Filter & Convert KKS Cards](filter-convert-kks-cards.md) | Finds KK and KKS cards and scenes, converts KKS to KK, and extracts archives. |
| [Filter Duplicate Contents](filter-duplicate-contents.md) | Finds duplicate cards and zipmods by content and moves or deletes the copies. |
| [Download Missing Mods](download-missing-mods.md) | Finds mods your cards, scenes and coordinates need but you don't have, and downloads them. |
| [Compress Card Textures](compress-card-textures.md) | Recompresses the textures inside cards with KoiCardTexTool. |
| [Install Contents](install-contents.md) | Copies cards, scenes, overlays and zipmods into the game folders. |
| [Uninstall Contents](uninstall-contents.md) | Reverses Install Contents. |
| [Group Characters](group-characters.md) | Sorts character cards into series folders, using an LLM. |
| [Ungroup Cards](ungroup-cards.md) | Moves cards from subfolders back to the top level. |
| [Rename Characters](rename-characters.md) | Translates character names, using an LLM. |
| [Archive Cards](archive-cards.md) | Bundles cards with the zipmods they need into one archive. |
| [Delete Cards](delete-cards.md) | Sends cards and their zipmods to the Recycle Bin. |
| [Export Mods](export-mods.md) | Copies mods out of your game by GUID. |
| [Delete Unused Mods](delete-unused-mods.md) | Sends zipmods that no card, scene or coordinate uses to the Recycle Bin. |
| [Group Scenes](group-scenes.md) | Sorts Studio scenes into per-author folders. |
| [Review Similar Characters](review-similar-characters.md) | Finds characters saved more than once and lets you choose which to remove. |
| [Organize Library](organize-library.md) | A library window for sorting scenes, characters and coordinates into folders by hand. |
