# Group Characters

- Groups character cards into subfolders named after their series, using an LLM. Works on KK, KKSP, and KKS character cards (KKS cards are only moved, never modified).
- Workflow:
  1. Customise the prompt if desired, optionally set a **Custom Chara Directory**, and enable **Group Characters**.
  2. Click **Start** — KKAFIO scans the chara folder(s), builds a JSON mapping `{character_key: ""}`, and opens a dialog showing the combined prompt + JSON.
  3. Click **Copy** in the dialog, paste into your LLM of choice. The LLM fills in the series name for each key.
  4. Copy the LLM's reply, click **Paste** in the same dialog — KKAFIO immediately moves each card into `<chara folder>/<series>/`.
- **Grouping by hand** — this task always uses the LLM workflow above. To type each character's series yourself, use the [Organize Library](organize-library.md) task.
- **Custom Chara Directory** — blank by default, which means the game's `UserData/chara/female` and `UserData/chara/male` folders, both handled in one run. The game only reads cards inside those two folders, so cards are only ever grouped inside the folder they're already in (`female/<series>/` or `male/<series>/`) — never directly in `UserData/chara`. Pointing the option at the game's `UserData/chara` folder behaves the same as leaving it blank. Any other folder (such as a staging folder) is grouped as a single folder.
- **Include subfolders** option lets you export already-sorted cards too (off by default to skip them).
- **Use Cache** _(on by default)_ — remembers each card's identification key (last name, first name, nickname, personality, hair colour) and birthday (birth month and day, stored apart from the key) in `kkafio_chara_key_cache.json` inside each chara folder, keyed by the file's mtime + size, so a repeat run only reads new or changed cards instead of parsing every card (twice) each time. Cards that aren't chara cards are remembered too. The cache is kept up to date as cards are moved — a moved card's entry follows it into its series folder — and is saved when the run ends. Shared with Rename Characters.
- **Prompt Language** _(`en_us` by default; CLI: `--prompt-language`)_ — which prompt is sent to the LLM. A language (`en_us`, `zh_cn`, `zh_tw`, `ja_jp`, `ko_kr`, `ru_ru`) sends the built-in prompt for that language, which asks for series titles in it; the prompt text is then ignored. `custom` sends the **Custom Prompt** text instead. When **Hints Language** is `detect`, the hints use the prompt language too (with `custom` the language is read from the prompt text, as before).
- **Resolve Locally** _(on by default; needs **Hints Language** other than `no`)_ — decides the easy cards without the LLM. A card whose name matches exactly one character in the character indexes gets that character's series; when several characters match, the one whose birth month and day (`birthMonth` / `birthDay` in the card's parameters, `birthMonth` / `birthDay` in the indexes) equal the card's wins. A card nobody matches that way still goes to the LLM, and a name whose cards are all resolved is left out of the prompt (if nothing is left, the dialog is skipped). If the matching character's series has no title in the hints language, it isn't assigned locally: the LLM gets that character as the only hint instead. CLI: `--resolve-locally` / `--no-resolve-locally`.
- **Open LLM Website** _(on by default)_ — opens the LLM website in your default browser right before the Copy/Paste dialog appears, so you can paste the prompt straight into it. Turn off if you already have your LLM open.
- **LLM Website URL** _(`https://claude.ai/` by default)_ — the page opened by **Open LLM Website**. Must start with `http://` or `https://`; if it is blank the default is used. Set it to your preferred LLM (e.g. `https://chat.deepseek.com/`). This option and the one above are separate for Group and Rename Characters.
- **Recommended LLMs:**
  - [Claude](https://claude.ai) — recommended, and the default. Use **Sonnet 5.5** with **low effort**: with the hints from the character indexes it identifies characters more accurately than DeepSeek, and it also copes well with Japanese anime and game characters.
  - [DeepSeek](https://chat.deepseek.com) — large context window and good at Chinese gacha games (Genshin Impact, Honkai Star Rail, Arknights); enable **Expert** for obscure characters. However, it can stop partway because of censorship when translating characters into Chinese, so it is less reliable than Claude for that.
